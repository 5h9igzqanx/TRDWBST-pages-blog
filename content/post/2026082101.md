### Java的历史及其特点

Java诞生于1995年。

在1995年之前，Sun公司（太阳微电子公司，现被Oracle公司（甲骨文公司）收购）曾令James Gosling团队开发过一种被称为Oak的语言以占领智能电子消费市场。

在1996年诞生了JDK（Java Development Kit，Java开发工具包）1.0。

Java的特点：

1. 简单性：相对某些编程语言来说比较简单。例如，Java不再支持C++中复杂的多继承；Java屏蔽了指针的概念……

2. 面向对象（OO）：Java纯面向对象，更符合人的思维模式。

3. 可移植性，跨平台：Java程序先在一个虚拟的系统JVM上运行，JVM再和底层操作系统交互，故Java编译后可以运行在任何操作系统上而不用再做适配。

4. 多线程：……

5. 健壮性：Java有自动垃圾回收机制（GC），可以自动回收内存空间。

6. 安全：Java仍在维护。

Java依靠C++实现。

对于Java代码的运行，有2个步骤：编译和运行。

编译的时候，Java编译器（在Windows系统中是`javac.exe`）把`.java`源代码文件编译成`.class`字节码文件。

运行的时候，Java运行器（`java.exe`）会启动一个JVM虚拟机，JVM启动一个ClassLoader类加载器，类加载器会把`.class`文件转为二进制编码，机器再运行二进制编码。

### 准备

#### 电脑的配置

至少需要打开文件扩展名显示。

Windows7系统：按<kbd>Windows</kbd>+<kbd>E</kbd>打开文件资源管理器，选择上面一栏的“查看”，选择“文件夹选项”，选择“查看”标签，在下面的栏目中取消勾选“隐藏已知文件类型的扩展名”。

Windows10或11系统：按<kbd>Windows</kbd>+<kbd>E</kbd>打开文件资源管理器，选择上面一栏的“查看”，在“显示/隐藏”栏目中勾选“文件扩展名”。

#### 环境的配置

想要使用Java，首先需要安装JDK。

打开[甲骨文官网](https://www.oracle.com/java/technologies/downloads/)，选择符合操作系统的版本安装。课程里演示的版本是JDK1.7.0，现在最新的版本是JDK26，选择的版本最好要大于JDK18。

在Oracle官网下载安装包之后双击打开安装，更改并记住安装的路径，路径里不能有中文，若弹出提示要安装jre，若不需要可不理会，关闭窗口。

安装完成之后打开设置，选择系统-系统信息-高级系统设置-环境变量，在下面新建变量为`JAVA_HOME`，内容是JDK安装的位置；再打开PATH，选择添加，写`%JAVA_HOME%/bin`。然后一路点确定。

然后安装一个IDE或代码编辑器，这里推荐Microsoft Visual Studio Code。

打开[Visual Studio Code官网](https://code.visualstudio.com/)，下载安装包，双击打开，更改安装的路径，也一样不能有中文。

安装完成之后双击打开，点左边“Extention”，在弹出的栏目上面的搜索框输入“Chinese”，选择第一个结果，点“Install”，安装中文插件。

然后在刚刚的界面搜素“Java”，选择第一个点击“安装”。点击左下角的“齿轮”图标，选择“设置”，在上面的搜索框输入“java.home”，选择第一个结果下面的“在settings.json中编辑”，把你的JDK的安装路径复制进去，把反斜杠改为斜杠，类此：

```json
{
    ...
    "java.jdt.ls.java.home":"C:/Program Files/Java/JDK26",//例如这是你的JDK安装路径
}
```

然后按照提示重启软件。

如果想要测试你的环境，那么请看下面。

### 打印Hello World

在某个文件夹下面新建一个文件`HelloWorld.java`（一定要是这个名字），鼠标右键选择“打开方式”，选中你安装的代码编辑器，打开文件。

输入以下代码，要求一个字也不许错：

```java
public class HelloWorld{
    public static void main(String[] args){
        System.out.println("Hello world!");
    }
}
```

然后在这个文件夹的界面，在上面的地址栏输入cmd，回车。

在弹出的命令行窗口输入：

```shell
javac HelloWorld.java
```

如果不出意外，命令行界面将什么都不会输出，同时文件夹中会多出来一个名为`HelloWorld.class`的文件。

然后在命令行窗口输入：

```shell
java HelloWorld
```

然后你将在命令行界面看到：

```text
Hello world!
```

那么，你的环境没有问题。

如果提示`'javac' 不是内部或外部命令，也不是可运行的程序或批处理文件。`或`'java' 不是内部或外部命令，也不是可运行的程序或批处理文件。`，那么确保你按照上面的步骤进行了配置。

如果提示中有类似`1个错误`等的字样，那么确保你在输入代码的时候没有输错。

在这里先解释一下这个源代码：

```java
public class HelloWorld{ /* 定义一个公开的类，名为HelloWorld，此处类名与文件名保持一致。 */
    // 以下是这个类的类体。除声明变量之外，这里不允许直接写Java语句。
    public static void main(String[] args){ /* 定义一个公开的静态的方法，名为main，包含一个名为args的参数，作为类的主方法、程序主入口。这部分属于样板代码，需要死记。 */
        // 以下是这个方法的方法体。
        System.out.println("Hello world!"); /* 使用System类中的println方法在控制台打印给定的字符串"Hello world!" */
        // Java语句必须以英文分号结束。
    }
}
```

这部分实际上是这个程序的入口，这部分的代码需要死记。

### 注释

在编写程序时，有时候需要给程序做解释，这部解释不能直接放进代码中，而是需要以注释的形式存在。

Java中的注释有3种形式：单行注释、多行注释和Javadoc注释。

单行注释以两个斜杠开头，后面写注释，例如：

```java
System.out.println("aaa"); // 这是单行注释
```

多行注释以一个斜杠和一个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，例如

```java
/*
这是多行注释
可以写很多行
*/
```

Javadoc注释用以标注这个程序的一些信息，可以被Java识别并生成帮助文档，以一个斜杠和两个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，每行开头加一个星号，例如：

```java
/**
 * 这是Javadoc注释
 * 也可以写很多行
 * 每行以星号开头
 * 可以被Java识别并且生产帮助文档
 * 一般用来写这个程序的一些信息和使用方法
 */
```

### 类的初步认识

在上面介绍的Hello World程序中，我们曾写道：

```java
public class HelloWorld{
    ...
}
```

这里定义了一个公开的类，作为这个程序的主体。

每个`.java`文件中都可以定义类，并且可以定义多个类，也可以不定义公开类。

例如：

```java
class A{}
class B{}
class X{}
class Y{}
public class K{}
```

这里`A`、`B`、`X`、`Y`、`K`都是类，其中K是一个公开的类。

公开的类的名称需要和文件名保持一致，所以一个文件只能定义一个公开类。

你可以再新建一个`.java`文件来学习这部分内容，例如`K.java`。

在`K.java`中输入以上代码，再打开命令提示符，输入

```shell
javac K.java
```

你会发现在文件夹下多出了`A.class`、`B.class`、`X.class`、`Y.class`、`K.class`5个文件。

在编译的时候每个类都会对应生成一个.class文件。
