### Java语言的历史及其特点

Java诞生于1995年。

在1995年之前，Sun公司（太阳微电子公司，现被Oracle公司（甲骨文公司）收购）曾令James Gosling团队开发过一种被称为Oak的语言以占领智能电子消费市场。

关于Java名称的由来：听说是开发人员在想名字时手里刚好端着一杯产自印度尼西亚爪洼岛（Java）的咖啡，所以有了这个名称和图标。

在1996年诞生了JDK（Java Development Kit，Java开发工具包）1.0。

Java语言的特点：

1. 简单性：相对某些编程语言来说比较简单。例如，Java不再支持C++中复杂的多继承；Java屏蔽了指针的概念……

2. 面向对象（OO）：Java纯面向对象，更符合人的思维模式。

3. 可移植性，跨平台：Java程序先在一个虚拟的系统JVM上运行，JVM再和底层操作系统交互，故Java编译后可以运行在任何操作系统上而不用再做适配。

4. 多线程：……

5. 健壮性：Java有自动垃圾回收机制（GC），可以自动回收内存空间。

6. 安全：Java仍在维护。

Java依靠C++实现。

对于Java代码的运行，有2个步骤：编译和运行。

编译的时候，Java编译器（在Windows系统中是`javac.exe`）把`.java`源代码文件编译成`.class`字节码文件。

运行的时候，Java运行器（`java.exe`）会启动一个JVM虚拟机，JVM启动一个ClassLoader类加载器，类加载器会把`.class`文件转为二进制编码，机器再运行二进制编码。

### 打印Hello World

在某个文件夹下面新建一个文件`HelloWorld.java`（**一定要是这个名字**），鼠标右键选择“打开方式”，选中你安装的代码编辑器，打开文件。

输入以下代码，要求**一个字也不许错**：

```java
public class HelloWorld{
    public static void main(String[] args){
        System.out.println("Hello world!");
    }
}
```

然后在这个文件夹的界面，在上面的地址栏输入cmd，回车。

在弹出的命令行窗口输入：`javac HelloWorld.java`。

如果不出意外，命令行界面将什么都不会输出，同时文件夹中会多出来一个名为`HelloWorld.class`的文件。

然后在命令行窗口输入：`java HelloWorld`。

然后你将在命令行界面看到：

```text
Hello world!
```

那么，你的环境没有问题。

如果提示`'javac' 不是内部或外部命令，也不是可运行的程序或批处理文件。`或`'java' 不是内部或外部命令，也不是可运行的程序或批处理文件。`，那么确保你按照上面的步骤进行了配置。

如果提示中有类似`1个错误`等的字样，那么确保你在输入代码的时候没有输错。

在这里先解释一下这个源代码：

```java
public class HelloWorld{ /* 定义一个公开的类，名为HelloWorld，此处类名与文件名保持一致。 */
    // 以下是这个类的类体。除声明变量之外，这里不允许直接写Java语句。
    public static void main(String[] args){ /* 定义一个公开的静态的方法，名为main，包含一个名为args的参数，作为类的主方法、程序主入口。这部分属于样板代码，需要死记。 */
        // 以下是这个方法的方法体。
        System.out.println("Hello world!"); /* 使用System类中的println方法在控制台打印给定的字符串"Hello world!" */
        // Java语句必须以英文分号结束。
    }
}
```

这部分实际上是这个程序的入口，这部分的代码需要死记。

### 注释

在编写程序时，有时候需要给程序做解释，这部解释不能直接放进代码中，而是需要以**注释**的形式存在。

Java中的注释有3种形式：**单行注释**、**多行注释**和**Javadoc注释**。

单行注释以两个斜杠开头，后面写注释，例如：

```java
System.out.println("aaa"); // 这是单行注释
```

多行注释以一个斜杠和一个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，例如

```java
/*
这是多行注释
可以写很多行
*/
```

Javadoc注释用以标注这个程序的一些信息，可以被Java识别并生成帮助文档，以一个斜杠和两个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，每行开头加一个星号，例如：

```java
/**
 * 这是Javadoc注释
 * 也可以写很多行
 * 每行以星号开头
 * 可以被Java识别并且生产帮助文档
 * 一般用来写这个程序的一些信息和使用方法
 */
```

### 类的初步认识

在上面介绍的Hello World程序中，我们曾写道：

```java
public class HelloWorld{
    ...
}
```

这里定义了一个公开的**类**，作为这个程序的主体。

每个`.java`文件中都可以定义类，并且可以定义多个类，也可以不定义公开类。

例如：

```java
class A{}
class B{}
class X{}
class Y{}
public class K{}
```

这里`A`、`B`、`X`、`Y`、`K`都是类，其中K是一个公开的类。

公开的类的名称需要和文件名保持一致，所以**一个文件只能定义一个公开类**。

你可以再新建一个`.java`文件来学习这部分内容，例如`K.java`。

在`K.java`中输入以上代码，再打开命令提示符，输入`javac K.java`。

你会发现在文件夹下多出了`A.class`、`B.class`、`X.class`、`Y.class`、`K.class`5个文件。

在编译的时候每个类都会对应生成一个`.class`文件。

如果这时候在命令提示符窗口输入`java K`来运行`K`这个类，则会提示：

```text
错误: 在类 K 中找不到 main 方法, 请将 main 方法定义为:
   public static void main(String[] args)
```

如果你把源代码改为

```java
public class K{
    public static void main(String[] args){
    }
}
```

再运行，会发现程序不再报错。这说明：

**每个类中都可以有`main`方法。执行对应的`.class`文件时会调用其`main`方法，若不存在`main`方法则在执行时报错，提示找不到`main`方法。**

### 标识符

**标识符**是在源代码中可以自己命名的单词。标识符可以标记类名、方法名、变量名、常量名、接口名。

标识符只能由以下元素构成：

- 大小写英文字母（区分大小写）

- 中文字符

- 数字（不能以此开头）

- 下划线`_`

- 美元符号`$`

标识符理论上没有字数限制，但是最好不要太长，保持其可读性。

要注意的是，**标识符不能命名为关键字**。

标识符一般遵循如此的命名规范：

1. 驼峰命名法，即名称中第二个及以后的单词首字母大写，单词中间无分隔。

2. 类名、接口名首字母大写，方法名、变量名首字母小写，常量名全部大写。

例如，以下是合法的标识符：

- `_Acs12`

- `Ac_s`

- `$hello2`

- `userName`

- `public0`

又如，以下是不合法的标识符：

| 不合法的标识符     | 不合法原因 |
| ----------- | ----- |
| `12Acs`     | 以数字开头 |
| `Ac-s`      | 包含减号  |
| `hello#2`   | 包含井号  |
| `user name` | 包含空格  |
| `public`    | 是关键字  |

示范：

```java
public class BiaoShiFuKnowledge{ /* BiaoShiFuKnowledge是一个类名 */
    int CHANGLIANG1 = 114514; /* CHANGLIANG1是一个常量名 */
    String bianLiang1 = "a"; /* bianLiang1是一个变量名 */
    public static void fangFa(){ /* fangFa是一个方法名 */
        String bianLiang2 = "2"; /* bianLiang2是一个变量名 */
        System.out.println(bianLiang2);
    }
    public static void main(String[] args){ /* main是主方法名，不能自主命名，但是也是标识符 */
        fangFa();
    }
}
```

### 字面值

**字面值**就是字面上能看出来内容的值，即数据。

字面值的类型有5种：

1. 整数型字面值 主要是int `1`、`2`、`36`

2. 浮点型字面值 float `2.71`、`3.14`

3. 布尔型字面值 boolean `true`、`false`

4. 字符串型字面值 String `"字符串"`、`"abc"`

5. 字符型字面值 char `'字'`、`'a'`

注意：字符外面套英文单引号，字符串外面套英文双引号

注意：字面值类型和数据类型不太相似，在后面解释数据类型。

注意，在一个文件中如果多次访问同一个字面值，每次访问的字面值占用的内存空间是不同的；如果把这个字面值赋值给一个变量，每次访问的变量的字面值占用的内存空间是相同的，这些后面会讲。

示范：

```java
public class ZiMianZhiKnowledge {
    public static void main(String[] args){
        System.out.println(12); /* 整数型字面值 */
        System.out.println(2.71828); /* 浮点型字面值 */
        System.out.println(true); /* 布尔型字面值 */
        System.out.println("字符串"); /* 字符串型字面值，使用双引号 */
        System.out.println('字'); /* 字符型字面值，使用单引号 */
    }
}
```

### 数据类型

数据的类型是**数据类型**。

数据类型在运行程序的时候指导JVM决定为数据分配的内存空间的大小。

Java中的数据类型分为基本数据类型和引用数据类型两种。在这里讲解基本数据类型。

#### 基本数据类型

基本数据类型分为4类8种。

1. 整数型
   1. 字节 byte 1字节
   2. 短整型 short 2字节
   3. 整型 int 4字节
   4. 长整型 long 8字节
2. 浮点型
   1. 单精度 float 4字节
   2. 双精度 double 8字节
3. 布尔型
   1. 布尔型 boolean 1字节
4. 字符型
   1.字符型 char 2字节

注意，字符串属于引用数据类型，不要与字符混淆。

口诀：“一二四八四八一二”

#### 二进制

**二进制**是数据的一种表示形式，使用0和1表示数据，满二进一。

由于计算机在任何情况下都只能识别二进制（高电平（1）和低电平（0）2种状态），故了解二进制对于编程的学习是有必要的。

一个0或1所占的单位叫做**比特位**（bit）。

二进制转换为十进制，把每一位上的数分别乘2的位数减一次幂，然后相加。（例如$0b1111=1\times2^3+1\times2^2+1\times2^1+1\times2^0=8+4+2+1=15$）

十进制转换为二进制，使用短除法，余数逆序组合。（例如$13\div2=6...1,6\div2=3...0,3\div2=1...1,1\div2=0...1$，故$13=0b1101$）

实在不想算了就按<kbd>Windows</kbd>+<kbd>R</kbd>输入`calc`回车，用计算器算吧。

#### 字节

1 Byte = 8 bit

由此向下延伸：

1kB（千字节）=1,024Byte

1MB（兆字节）=1,024kB

1GB（吉字节）=1,024MB

1TB（太字节）=1,024GB（1TB=8,796,093,022,208bit）

例如，你买的2TB硬盘到手只有1.81TB是因为商家是按照1TB=$1,000^4$Byte计算的，而计算机是按照1TB=$1,024^4$Byte计算的。

数字有正负号区分，故在计算机中，在数字的二进制表示当中会匀出最左边的一个比特位称作“**符号位**”用于存放正负号。0表示正数，1表示负数。

所以byte类型真正存数据的只有7个比特位，其最大值是01111111（等于10000000-1），即127。

#### 字符编码的初步认识

由上可知，char类型表示的是字符，字符一般是不能像数字一样直接转换为二进制数的。

为了让计算机可以表示现实世界的文字，我们需要提前制定好“文字”和“二进制数”之间的对照关系。这种对照转换关系被称为**字符编码**。

也就是说，字符编码是各国计算机协会制定好的一种二进制数与文字之间的对照关系。

最早的字符编码是ASCII码，仅仅规定了26个英文字母、10个数字和部分英文标点符号。其规定的字符总数不超过256个，所以其仅需1个字节便可表示一个字符。

例如，在这种字符编码中，有：

```text
'a' -> 97 -> 0b01100001
'b' -> 98 -> 0b01100010
'A' -> 65 -> 0b01000001
'B' -> 66 -> 0b01000010
'0' -> 48 -> 0b00110000
'1' -> 49 -> 0b00110001
```

后来随着计算机的发展，国际化标准组织（ISO）制定了一种编码方式称作ISO-8859-1（又称Latin-1），这种字符编码支持西欧语言，向上兼容ASCII码，仍然不支持中文。

随着计算机向亚洲发展，计算机开始支持中日韩等国家文字。当时支持简体中文的字符编码有：GBK、GB2312、GB18310（GB1831包括的中文字符最多，其它的依次递减）。当时支持繁体中文的字符编码有：big5。

后来出现了一种支持全球所有字符的字符编码，称作Unicode编码。这套字符编码有多种具体实现，例如UTF-8、UTF-16、UTF-32。

Java语言采用Unicode编码（主要是UTF-8），故**标识符可以有中文**。例如：在`类.class`中写`public class 类{}`，编译的话不会报错。

把字符按照字符编码转化为二进制数的过程叫做**解码**，把二进制数转化为字符的过程叫做**编码**。编码和解码的时候需要采用同一套字符编码，否则会出现乱码的现象。

#### 各种基本数据类型支持的数值范围（摘自[Java官方文档](https://docs.oracle.com/en/java/javase/26/docs/specs/jls/jls-4.html#jls-4.1)）

| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |

| `long`    | $\mathbb{N}\cap[-9,223,372,036,854,775,808,\ \ 9,223,372,036,854,775,807]$                                                                           | 0          |
| `float`   | $\\{ s\times m\times 2^{e-n+1}\mid s\in \\{ 1,-1 \\} ,m\in \\{ i\in\mathbb{N}\mid i<2^n \\} ,e\in\mathbb{N}\cap[-2^{K-1-2},2^{K-1-1}],n=24,K=8 \\}$  | `0.0f`     |

### 变量

**变量**本质上是内存中的一块空间，这块空间有数据类型、名称和字面值。

**变量是内存中存储数据的最基本的单元。**

#### 变量的声明、赋值和读取

##### 变量的声明

声明一个变量，让程序知道这个变量的存在。

例如你拿出一个信封，上面写上变量名，这个写有变量名的信封就可以当作一个变量。

变量声明的语法结构：`数据类型 变量名;`

例如：

```java
int a;
```

一个变量只能声明一次。同作用域中变量不能重名。（有关作用域的知识点见下）

##### 变量的赋值

给这个变量赋值，让其存储数据。变量在赋值时才会拥有专门的内存空间，此后才能被访问。

例如你拿出一张A4纸，在纸上写下这个变量要存储的字面值，把这张纸装进代表变量的信封，这个内含一张写有内容的纸的信封就是赋值过的变量。

变量赋值的语法结构：`变量名=字面值;`

例如：

```java
a = 1;
```

等号是一个运算符，代表赋值。其作用是运算等号右边的表达式，然后把结果赋值给左边的变量或常量。

##### 变量的访问（读取）

访问这个变量，只需要写出这个变量的名字。

多次访问同一个变量，访问的内存地址是相同的。例如你一次又一次地打开那个信封看里面的A4纸上的内容，那张A4纸是不变的。

访问一个变量有2种方式：读取（get）和修改（重新赋值，set），修改那部分在上面说过了，这里讲的是读取。

```java
System.out.println(a);
System.out.println(a);
System.out.println(a); // 无论再怎么读取，变量a还是那个变量a。
```

变量在声明之后可以多次修改，不过每次赋值之后访问的内存空间与之前不同。

例如你把那个信封中的A4纸拿出来，换另一张干净的A4纸写上新的字面值再装进去，以后打开信封看见的A4纸就不是之前那张了。

```java
a = 1; //set
System.out.println(a); // get
a = 36; // set
System.out.println(a); // get
```

声明和赋值可以在同一行进行。

声明并赋值的语法结构：`数据类型 变量名=字面值;`

同一行可以同时声明多个数据类型相同的变量，每个变量之间用逗号隔开。

对于`int a,b,c=2;`来说，含义是声明a、b、c三个变量，其中c=2。a和b未赋值，不能访问。如果想对这3个变量使用这种形式声明并且都赋值，则上面语句改为`int a=2,b=2,c=2;`即可。

```java
int x=3,y=75,z=2;
System.out.println(x);
System.out.println(y);
System.out.println(z);
```

#### 变量的作用域和分类

**作用域**描述了变量的有效范围。

变量在作用域内可以被访问，在作用域外则无法被访问。

口诀：“出了大括号就不认识了。”

根据变声明的位置，变量可分为**局部变量**和**成员变量**。

在方法体内声明，作用域是整个方法体的变量是局部变量。在方法体外、类体内声明，作用域是整个类体或更小的变量是成员变量。

不同作用域的不同变量可以重名，同一作用域的不同变量不能重名。

示范：

```java
public class Class1{
    static int k = 9; // 这里k的作用域是整个类体，是成员变量。（static的作用目前没有学到，暂不理会）
    public static void func1(){
        System.out.println(k); // 这里可以访问k。
        int l = 8; // 这里l的作用域是整个方法体，是局部变量。
        System.out.println(l); // 这里可以访问l。
        for(int m = 0;m<10;m++){ // 这里m的作用域是整个for循环体。（for循环目前没有学到，暂不理会）
            System.out.println(m); // 这里可以访问m。
        }
        // System.out.println(m); // 这里不能访问m。
    }
    public static void func2(){
        System.out.println(k); //这里可以访问k。
        // System.out.println(l); //这里不能访问上面的l。
        int l = 9; // 这里l的作用域是整个方法体，是局部变量。在这个方法中重新声明的l不是上面声明的l。
        System.out.println(l);
        int k = 190; // 不同作用域的变量可以同名，不过在两个作用域是上下级关系的时候尽量不要这么做。
        System.out.println(k);
    }
}
```
