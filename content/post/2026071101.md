# 使用MathJax渲染LaTeX公式时很难看的硬核解决过程

今天我<ruby>摆<rt>bái</rt>弄<rt>gào</rt></ruby>好了我这里使用MathJax渲染的LaTeX公式显示，用最朴实无华的方法。

在我最初使用MathJax时，我直接把它的CDN源导入了进去没有做过多配置，于是它到处的结果有“亿”点奇葩，以至于所有的字都被莫名其妙的滚动条盖住了。

![原来的图(渲染了三角函数的降幂扩角公式)](https://5h9igzqanx.github.io/TRDWBST-media/picture/blog/contentRes/2026071101-01.png)

于是当时尚且年幼的我使用了最朴实无华的方法：

```css
mjx-cotainer,mjx-container *{
    overflow-y:hidden;
}
```

当然，这属于“手疼砍手，头疼砍头”的办法，治标不治本，但是总归能看下去……？

反正就是今天我誊笔记时看见这么个阴到没边的丑东西时，我愤怒了，于是我使用了——

- AI

- [https://docs.mathjax.org](https://docs.mathjax.org)

在我一阵瞎捣鼓之后，它——<br>更丑了。

但是，我机灵地发现，帮助文档中有这么一句话：

> The output processor uses Scalable Vector Graphics to render the mathematics on the page. The SVG output mode offers high-quality results, and displays and prints well in all browsers. Since it uses SVG data instead of font files, it is not affected by user-based web-font blocking, or other character-placement issues that sometimes occur with the HTML-based output.`SVG`
> 
> ——来自于[《SVG Support — MathJax 4.0 documentation》](https://docs.mathjax.org/en/latest/output/svg.html)

于是，我打算把输出从默认的chtml改为SVG。

具体做法是在MathJax的配置中如此这般地设置：

```javascript
window.MathJax={
    loader:{
        load:["outputy/svg"],
    },
    ...
}
```

然后把MathJax的CDN源改为专门渲染SVG的版本：

```html
<script id="MathJax-script" async src="https://cdn.jsdelivr.net/npm/mathjax@4/tex-svg.js"></script>
```

于是，解决了。

![解决之后](https://5h9igzqanx.github.io/TRDWBST-media/picture/blog/contentRes/2026071101-02.png)

对，解决了。

现在算是直接治成标本了也没什么毛病了，因为svg是不变的图像，没什么格式。

确实朴实无华，难易程度相当于我给手机充电时换了一个充电器。

反正就这吧，也给那些被此困扰的朋友们提供个方法。
