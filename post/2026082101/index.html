Java语言的历史及其特点

Java诞生于1995年。

在1995年之前，Sun公司（太阳微电子公司，现被Oracle公司（甲骨文公司）收购）曾令James Gosling团队开发过一种被称为Oak的语言以占领智能电子消费市场。

关于Java名称的由来：听说是开发人员在想名字时手里刚好端着一杯产自爪洼岛（Java）的咖啡，所以有了这个名称和图标。

在1996年诞生了JDK（Java Development Kit，Java开发工具包）1.0。

Java语言的特点：

  1. 简单性：相对某些编程语言来说比较简单。例如，Java不再支持C++中复杂的多继承；Java屏蔽了指针的概念……

  2. 面向对象（OO）：Java纯面向对象，更符合人的思维模式。

  3. 可移植性，跨平台：Java程序先在一个虚拟的系统JVM上运行，JVM再和底层操作系统交互，故Java编译后可以运行在任何操作系统上而不用再做适配。

  4. 多线程：……

  5. 健壮性：Java有自动垃圾回收机制（GC），可以自动回收内存空间。

  6. 安全：Java仍在维护。

Java依靠C++实现。

对于Java代码的运行，有2个步骤：编译和运行。

编译的时候，Java编译器（在Windows系统中是javac.exe）把.java源代码文件编译成.class字节码文件。

运行的时候，Java运行器（java.exe）会启动一个JVM虚拟机，JVM启动一个ClassLoader类加载器，类加载器会把.class文件转为二进制编码，机器再运行二进制编码。

准备

电脑的配置

至少需要打开文件扩展名显示。

Windows7系统：按Windows+E打开文件资源管理器，选择上面一栏的“查看”，选择“文件夹选项”，选择“查看”标签，在下面的栏目中取消勾选“隐藏已知文件类型的扩展名”。

Windows10或11系统：按Windows+E打开文件资源管理器，选择上面一栏的“查看”，在“显示/隐藏”栏目中勾选“文件扩展名”。

环境的配置

想要使用Java，首先需要安装JDK。

打开甲骨文官网，选择符合操作系统的版本安装。课程里演示的版本是JDK1.7.0，现在最新的版本是JDK26，选择的版本最好要大于JDK18。

在Oracle官网下载安装包之后双击打开安装，更改并记住安装的路径，路径里不能有中文，若弹出提示要安装jre，若不需要可不理会，关闭窗口。

安装完成之后打开设置，选择系统-系统信息-高级系统设置-环境变量，在下面新建变量为JAVA_HOME，内容是JDK安装的位置；再打开PATH，选择添加，写%JAVA_HOME%/bin。然后一路点确定。

然后安装一个IDE或代码编辑器，这里推荐Microsoft Visual Studio Code。

打开Visual Studio Code官网，下载安装包，双击打开，更改安装的路径，也一样不能有中文。

安装完成之后双击打开，点左边“Extention”，在弹出的栏目上面的搜索框输入“Chinese”，选择第一个结果，点“Install”，安装中文插件。

然后在刚刚的界面搜素“Java”，选择第一个点击“安装”。点击左下角的“齿轮”图标，选择“设置”，在上面的搜索框输入“java.home”，选择第一个结果下面的“在settings.json中编辑”，把你的JDK的安装路径复制进去，把反斜杠改为斜杠，类此：

2    ...

4}

然后按照提示重启软件。

如果想要测试你的环境，那么请看下面打印Hello World的部分。

命令提示符和一些常用的DOS命令

Windows的前身是MS-DOS，而今的Windows系统仍然保留着DOS命令行终端，即命令提示符。

用好命令提示符，可以对电脑的使用带来极大便利。

打印Hello World

在某个文件夹下面新建一个文件HelloWorld.java（一定要是这个名字），鼠标右键选择“打开方式”，选中你安装的代码编辑器，打开文件。

输入以下代码，要求一个字也不许错：

1public class HelloWorld{
2    public static void main(String[] args){
3        System.out.println("Hello world!");
4    }
5}

然后在这个文件夹的界面，在上面的地址栏输入cmd，回车。

在弹出的命令行窗口输入：javac HelloWorld.java。

如果不出意外，命令行界面将什么都不会输出，同时文件夹中会多出来一个名为HelloWorld.class的文件。

然后在命令行窗口输入：java HelloWorld。

然后你将在命令行界面看到：

1Hello world!

那么，你的环境没有问题。

如果提示'javac' 不是内部或外部命令，也不是可运行的程序或批处理文件。或'java' 不是内部或外部命令，也不是可运行的程序或批处理文件。，那么确保你按照上面的步骤进行了配置。

如果提示中有类似1个错误等的字样，那么确保你在输入代码的时候没有输错。

在这里先解释一下这个源代码：

1public class HelloWorld{ /* 定义一个公开的类，名为HelloWorld，此处类名与文件名保持一致。 */
2    // 以下是这个类的类体。除声明变量之外，这里不允许直接写Java语句。
3    public static void main(String[] args){ /* 定义一个公开的静态的方法，名为main，包含一个名为args的参数，作为类的主方法、程序主入口。这部分属于样板代码，需要死记。 */
4        // 以下是这个方法的方法体。
5        System.out.println("Hello world!"); /* 使用System类中的println方法在控制台打印给定的字符串"Hello world!" */
6        // Java语句必须以英文分号结束。
7    }
8}

这部分实际上是这个程序的入口，这部分的代码需要死记。

注释

在编写程序时，有时候需要给程序做解释，这部解释不能直接放进代码中，而是需要以注释的形式存在。

Java中的注释有3种形式：单行注释、多行注释和Javadoc注释。

单行注释以两个斜杠开头，后面写注释，例如：

1System.out.println("aaa"); // 这是单行注释

多行注释以一个斜杠和一个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，例如

1/*
2这是多行注释
3可以写很多行
4*/

Javadoc注释用以标注这个程序的一些信息，可以被Java识别并生成帮助文档，以一个斜杠和两个星号开头，以一个星号和一个斜杠结束，中间写注释，可以换行，每行开头加一个星号，例如：

1/**
2 * 这是Javadoc注释
3 * 也可以写很多行
4 * 每行以星号开头
5 * 可以被Java识别并且生产帮助文档
6 * 一般用来写这个程序的一些信息和使用方法
7 */

类的初步认识

在上面介绍的Hello World程序中，我们曾写道：

1public class HelloWorld{
2    ...
3}

这里定义了一个公开的类，作为这个程序的主体。

每个.java文件中都可以定义类，并且可以定义多个类，也可以不定义公开类。

例如：

1class A{}
2class B{}
3class X{}
4class Y{}
5public class K{}

这里A、B、X、Y、K都是类，其中K是一个公开的类。

公开的类的名称需要和文件名保持一致，所以一个文件只能定义一个公开类。

你可以再新建一个.java文件来学习这部分内容，例如K.java。

在K.java中输入以上代码，再打开命令提示符，输入javac K.java。

你会发现在文件夹下多出了A.class、B.class、X.class、Y.class、K.class5个文件。

在编译的时候每个类都会对应生成一个.class文件。

如果这时候在命令提示符窗口输入java K来运行K这个类，则会提示：

1错误: 在类 K 中找不到 main 方法, 请将 main 方法定义为:
2   public static void main(String[] args)

如果你把源代码改为

1public class K{
2    public static void main(String[] args){
3    }
4}

再运行，会发现程序不再报错。这说明：

每个类中都可以有main方法。执行对应的.class文件时会调用其main方法，若不存在main方法则在执行时报错，提示找不到main方法。

标识符

标识符是在源代码中可以自己命名的单词。标识符可以标记类名、方法名、变量名、常量名、接口名。

标识符只能由以下元素构成：

  • 大小写英文字母（区分大小写）

  • 数字（不能以此开头）

  • 下划线_

  • 美元符号$

标识符理论上没有字数限制，但是最好不要太长，保持其可读性。

要注意的是，标识符不能命名为关键字。

标识符一般遵循如此的命名规范：

  1. 驼峰命名法，即名称中第二个及以后的单词首字母大写，单词中间无分隔。

  2. 类名、接口名首字母大写，方法名、变量名首字母小写，常量名全部大写。

例如，以下是合法的标识符：

  • _Acs12

  • Ac_s

  • $hello2

  • userName

  • public0

又如，以下是不合法的标识符：

不合法的标识符不合法原因
12Acs以数字开头
Ac-s包含减号
hello#2包含井号
user name包含空格
public是关键字

示范：

 1public class BiaoShiFuKnowledge{ /* BiaoShiFuKnowledge是一个类名 */
 2    int CHANGLIANG1 = 114514; /* CHANGLIANG1是一个常量名 */
 3    String bianLiang1 = "a"; /* bianLiang1是一个变量名 */
 4    public static void fangFa(){ /* fangFa是一个方法名 */
 5        String bianLiang2 = "2"; /* bianLiang2是一个变量名 */
 6        System.out.println(bianLiang2);
 7    }
 8    public static void main(String[] args){ /* main是主方法名，不能自主命名，但是也是标识符 */
 9        fangFa();
10    }
11}

关键字的初步认识

关键字是Java在开发时被提前定义有特殊含义的单词。

关键字全部小写，不能用作标识符。

可以在Java官方文档查看目前已有的关键字：

abstract assert boolean break byte case catch char class const continue default do double else enum extends final finally float for if goto implements import instanceof int interface long native new package private protected publoc return short static strictfp super switch synchronized this throw throws transient try void volatile while

exports module non-sealed open opens permits provides record requires sealed to transitive uses var when with yield

这些关键字没必要专门记，在以后的学习和使用中会积累。

字面值

字面值就是字面上能看出来内容的值，即数据。

字面值的类型有5种：

  1. 整数型字面值 主要是int 1、2、36

  2. 浮点型字面值 float 2.71、3.14

  3. 布尔型字面值 boolean true、false

  4. 字符串型字面值 String "字符串"、"abc"

  5. 字符型字面值 char '字'、'a'

注意字面值类型和数据类型不太相似，在后面解释数据类型。

注意，在一个文件中如果多次访问同一个字面值，每次访问的字面值占用的内存空间是不同的；如果把这个字面值赋值给一个变量，每次访问的变量的字面值占用的内存空间是相同的，这些后面会讲。

示范：

1public class ZiMianZhiKnowledge {
2    public static void main(String[] args){
3        System.out.println(12); /* 整数型字面值 */
4        System.out.println(2.71828); /* 浮点型字面值 */
5        System.out.println(true); /* 布尔型字面值 */
6        System.out.println("字符串"); /* 字符串型字面值，使用双引号 */
7        System.out.println('字'); /* 字符型字面值，使用单引号 */
8    }
9}

数据类型

数据的类型是数据类型。

数据类型在运行程序的时候指导JVM决定为数据分配的内存空间的大小。

Java中的数据类型分为基本数据类型和引用数据类型两种。在这里讲解基本数据类型。

基本数据类型

基本数据类型分为4类8种。

  1. 整数型
    1. 字节 byte 1字节
    2. 短整型 short 2字节
    3. 整型 int 4字节
    4. 长整型 long 8字节
  2. 浮点型
    1. 单精度 float 4字节
    2. 双精度 double 8字节
  3. 布尔型
    1. 布尔型 boolean 1字节
  4. 字符型 1.字符型 char 2字节

注意，字符串属于引用数据类型，不要与字符混淆。

口诀：“一二四八八四二一”

二进制

二进制是数据的一种表示形式，使用0和1表示数据，满二进一。

由于计算机在任何情况下都只能识别二进制（高电平（1）和低电平（0）2种状态），故了解二进制对于编程的学习是有必要的。

一个0或1所占的单位叫做比特位（bit）。

二进制转换为十进制，把每一位上的数分别乘2的位数减一次幂，然后相加。（例如$0b1111=1\times2^3+1\times2^2+1\times2^1+1\times2^0=8+4+2+1=15$）

十进制转换为二进制，使用短除法，余数逆序组合。（例如$13\div2=6…1,6\div2=3…0,3\div2=1…1,1\div2=0…1$，故$13=0b1101$）

实在不想算了就按Windows+R输入calc回车，用计算器算吧。

字节

1 Byte = 8 bit

由此向下延伸：

1kB（千字节）=1,024Byte

1MB（兆字节）=1,024kB

1GB（吉字节）=1,024MB

1TB（太字节）=1,024GB（1TB=8,796,093,022,208bit）

例如，你买的2T硬盘到手只有1.81T是因为商家是按照1TB=$1,000^4$Byte计算的，而计算机是按照1TB=$1,024^4$Byte计算的。

数字有正负号区分，故在计算机中，在数字的二进制表示当中会匀出最左边的一个比特位称作“符号位”用于存放正负号。0表示正数，1表示负数。

所以byte类型真正存数据的只有7个比特位，其最大值是01111111（等于10000000-1），即127。

各种基本数据类型支持的数值范围（摘自Java官方文档）

byte i $\in[-128,127]$

short i $\in[-32768,32767]$

int i $\in[-2,147,483,648,\ \ 2,147,483,647]$

long i $\in[-9,223,372,036,854,775,808,\ \ 9,223,372,036,854,775,807]$

float i $\in \left{ s\times m\times 2^{e-n+1}|s\in \left{ 1,-1 \right} ,m\in \left{ i\in\mathbb{N}|i<2^n \right} ,e\in\mathbb{N}\cap[-2^{K-1-2},2^{K-1-1}],n=24,K=8 \right}$

double i $\in \left{ s\times m\times 2^{e-n+1}|s\in \left{ 1,-1 \right} ,m\in \left{ i\in\mathbb{N}|i<2^n \right} ,e\in\mathbb{N}\cap[-2^{K-1-2},2^{K-1-1}],n=53,K=11 \right}$

boolean i $\in\{true,false\}$

char i $\in[0,65535]$

变量

变量本质上是内存中的一块空间，这块空间有数据类型、名称和字面值。

变量是内存中存储数据的最基本的单元。

变量的声明、赋值和读取

变量的声明

声明一个变量，让程序知道这个变量的存在。

例如你拿出一个信封，上面写上变量名，这个写有变量名的信封就可以当作一个变量。

变量声明的语法结构：数据类型 变量名;

例如：

1int a;

一个变量只能声明一次。同作用域中变量不能重名。（有关作用域的知识点见下）

变量的赋值

给这个变量赋值，让其存储数据。变量在赋值时才会拥有专门的内存空间，此后才能被访问。

例如你拿出一张A4纸，在纸上写下这个变量要存储的字面值，把这张纸装进代表变量的信封，这个内含一张写有内容的纸的信封就是赋值过的变量。

变量赋值的语法结构：变量名=字面值;

例如：

1a = 1;

等号是一个运算符，代表赋值。其作用是运算等号右边的表达式，然后把结果赋值给左边的变量或常量。

变量的访问（读取）

访问这个变量，只需要写出这个变量的名字。

多次访问同一个变量，访问的内存地址是相同的。例如你一次又一次地打开那个信封看里面的A4纸上的内容，那张A4纸是不变的。

访问一个变量有2种方式：读取（get）和修改（重新赋值，set），修改那部分在上面说过了，这里讲的是读取。

1System.out.println(a);
2System.out.println(a);
3System.out.println(a); // 无论再怎么读取，变量a还是那个变量a。

变量在声明之后可以多次修改，不过每次赋值之后访问的内存空间与之前不同。

例如你把那个信封中的A4纸拿出来，换另一张干净的A4纸写上新的字面值再装进去，以后打开信封看见的A4纸就不是之前那张了。

1a = 1; //set
2System.out.println(a); // get
3a = 36; // set
4System.out.println(a); // get

声明和赋值可以在同一行进行。

声明并赋值的语法结构：数据类型 变量名=字面值;

同一行可以同时声明多个数据类型相同的变量，每个变量之间用逗号隔开。

对于int a,b,c=2;来说，含义是声明a、b、c三个变量，其中c=2。a和b未赋值，不能访问。如果想对这3个变量使用这种形式声明并且都赋值，则上面语句改为int a=2,b=2,c=2;即可。

1int x=3,y=75,z=2;
2System.out.println(x);
3System.out.println(y);
4System.out.println(z);

变量的作用域和分类

作用域描述了变量的有效范围。

变量在作用域内可以被访问，在作用域外则无法被访问。

口诀：“出了大括号就不认识了。”

根据变声明的位置，变量可分为局部变量和成员变量。

在方法体内声明，作用域是整个方法体的变量是局部变量。在方法体外、类体内声明，作用域是整个类体或更小的变量是成员变量。

不同作用域的不同变量可以重名，同一作用域的不同变量不能重名。

示范：

 1public class Class1{
 2    static int k = 9; // 这里k的作用域是整个类体，是成员变量。（static的作用目前没有学到，暂不理会）
 3    public static void func1(){
 4        System.out.println(k); // 这里可以访问k。
 5        int l = 8; // 这里l的作用域是整个方法体，是局部变量。
 6        System.out.println(l); // 这里可以访问l。
